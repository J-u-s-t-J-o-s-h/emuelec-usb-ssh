# Pocket Meadow

A separate small 3D walking and collection game for Godot/FRT 4.1.3.
Walk freely, automatically collect 24 golden stars, hop with A, pause with Start,
and save/quit with Select. No enemies, time limit, drowning or rigid-body piles.
Progress saves after pickups and on quit. After all stars, A resets the collection.
All models, colors and the pickup tone are generated by this project.

## Verified evidence
- PC import, self-test and export completed using official Godot 4.1.3.
- Initial handheld benchmark: 59.98 FPS at native 720x720; ready at 4.672 seconds
  from engine start. See evidence/device-benchmark-initial.log. Individual frame
  times in that initial log use smoothed engine delta, not wall-clock intervals.
- Automated keyboard controls on FRT passed movement, hop, pause/resume,
  pickup, save/reload and Escape quit. See evidence/device-controls.log.
  All 24 collectible locations passed the obstacle-resolution check; this is not
  an exhaustive walking-path test. The wrapper restored EmulationStation.
- Captured handheld screenshot visually inspected: scene and UI render.
- [Unverified] Physical controls, perceived smoothness and full player route.
- Known diagnostics: headless PC shutdown emits two dummy-renderer mesh errors
  and an ObjectDB leak warning; controls harness also emits the leak warning.
  Both exit zero after passing checks. Cause has not been verified.

## Build and deployment
Build (WSL/Linux):

    sh build.sh /path/to/Godot_v4.1.3-stable_linux.x86_64 /path/to/output

Deploy game.pck, run-meadow.sh and meadow.gptk to
/storage/roms/ports/pocketmeadow/. Shared FRT and libstdc++ remain in
/storage/roms/ports/backyardbash/frt/. Keep handheld scripts LF.

Test detached with:

    systemd-run --unit=pocket-meadow-test --quiet sh /storage/roms/ports/pocketmeadow/test-meadow.sh

The test uses separate saves, runs a bounded benchmark, captures a screenshot,
and restores EmulationStation. controls-check.gd / test-controls.sh provide the
separate input/save/quit integration test. Install Pocket Meadow.sh in
ports_scripts only after testing; do not edit gamelist.xml. Backyard Bash remains
separate. Normal saves: pocketmeadow/savedata; test saves: test-savedata.
